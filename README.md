# 《新闻联播》文字稿仓库

每天中央电视台《新闻联播》节目文字稿的归档仓库。

## 简介

本仓库用于存储每天《新闻联播》(19:00 档) 的文字稿，方便日常查阅、整理与检索。

- **文字稿来源**：央视《新闻联播》节目语音识别转写整理（部分内容已修正明显识别错字）
- **文件存放**：所有文字稿存放在 [`docs/`](./docs/) 目录下，以播出日期命名

## 文件命名规则

每个文字稿文件按**播出日期**命名，格式为 `YYYYMMDD.md`：

```
docs/20260811.md   →   2026年8月11日 播出
```

> 说明：文件中保留 Markdown 语法，可在 GitHub 中直接在线预览。

## 使用方式

在线点击上方表格中的文件链接即可直接预览；如需批量下载，可使用 `git clone` 拉取整个仓库：

```bash
git clone https://github.com/zhangpeipei-dev/xinwenlianbo.git
```

## 说明

- 文字稿基于语音识别，人名、地名等专名可能存在个别误差，正式引用请以央视官方播出内容为准。
- 仓库会随每天节目播出持续更新归档。
